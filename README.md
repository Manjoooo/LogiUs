# 🚚 T-Check | AI 기반 화물 운송 신뢰도 & 현장 대응 플랫폼

**차주·화주·물류관리자를 하나의 데이터 흐름으로 연결하는 카카오 T 화물 확장형 어플리케이션**

기존 화물 운송 과정에서 발생하는 **현장 정보 부족, 돌발상황 대응 지연, 대기시간 및 운송 신뢰도 문제**를 해결하기 위해 기획했습니다.

차주의 실제 운송 과정에서 발생하는 데이터를 수집하고,
AI와 위치 기반 데이터를 활용해 **운송 전–운송 중–운송 후의 정보를 연결**합니다.

## 💡 Core Features

* 🎙️ **AI 음성 배차**
  운전 중에도 음성으로 조건에 맞는 화물을 탐색하고 배차

* 📡 **AI 현장 제보 & Field Radar**
  사고·도로 통제·상하차 지연 등 현장 상황을 음성으로 제보하고 주변 차주와 공유

* ✅ **T-Check 신뢰도 시스템**
  실제 운송 및 현장 데이터를 기반으로 화물·상하차 환경에 대한 신뢰 정보 축적

* 📍 **실시간 운송 관제**
  차량 위치, ETA 변화, 운송 진행 상황 및 돌발상황 확인

* 🏢 **화주·물류관리자 Dashboard**
  운송 현황과 현장 데이터를 통합하여 관리
